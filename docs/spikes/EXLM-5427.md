## False positives / quality (not a payload-format failure)

Kitchen-sink run `da3b18f6`: `final_score` 80 is the mean of seven categories `(100+81+82+100+0+100+100)/7`. Grammar **0** is a short-page floor on real SVA hits, not “no grammar.” Inclusive `BUG`→`ISSUE` and Tone `planted`→`example` are noisy. Clarity missed `utilize`. Table cell `was assign` still missed (same as July markdown).

That is model behavior (`gemini-3.1-flash-lite`), not “tags flagged as grammar.”

## Mapping / Fix

- `error.indices[0]` → `findSpanForOffset` → live field HTML → `locateInRawHtml(error_line)` → JSON patch.
- Plain `error_line` locates across tags (Fix drops inline markup in the replaced span, by design).
- When HTML scoring **echoes tags** in `error_line` (`Click <b>Save</b>…`), locate searched only the plain rendering and Fix returned “text has changed.” Spike follow-up in the extension: match tagged `error_line` against raw HTML first.

Duplicate sentences still hit the first match (existing TODO).
